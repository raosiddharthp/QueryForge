# ADR-001: Google Cloud-only architecture over open-source, multi-vendor stack

**Status:** Accepted

## Context

The original design used ChromaDB, local HuggingFace inference for embeddings and reranking,
and Hugging Face Spaces for hosting. This deployment runs on a Google Cloud free-tier account
with zero credits, sharing a billing account with three other apps. A multi-vendor stack adds
operational surface area — separate hosting, separate credentials, separate failure modes —
with no benefit on this constraint set.

## Decision

Rebuild on Google Cloud only: Cloud Run for compute, Firestore for persistence and vector
search, Cloud Storage for corpus and model weights, and the Gemini Developer API for the one
LLM dependency. Any component without a viable Always-Free Google Cloud home is either
self-hosted inside the Cloud Run container or dropped.

## Consequences

All diagrams, stack references, and deploy instructions assume Google Cloud only. Self-hosted
open-weight models remain in the design (ADR-003) — "Google Cloud-only" means the
infrastructure vendor, not that every model call must be a managed API.

## Alternatives

- **Keep the original multi-vendor stack** — rejected. Hugging Face Spaces hosting and
  self-hosted ChromaDB have no committed zero-cost guarantee compatible with a $0.01 ceiling,
  and add credentials outside Google's IAM boundary.
