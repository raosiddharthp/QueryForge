# ADR-005: Cloud Run over GKE Autopilot

**Status:** Accepted

## Context

QueryForge needs a container runtime for the FastAPI service and its self-hosted models. GKE
Autopilot is the Google-native alternative, but even a minimal Autopilot cluster bills for a base
management fee and any always-on node, regardless of traffic — a cost floor that a near-zero-traffic
demo cannot justify against a $0.01 cap.

## Decision

Deploy to Cloud Run (`infra/main.tf`) with `max_instance_count` capped at 3 and
`min_instance_count = 0` (scale-to-zero). When there is no traffic, there is no running instance
and no charge.

## Consequences

Cold starts add latency to the first request after idle periods — self-hosted model loading
(`embeddings.py`) adds to this, since `sentence-transformers` and `cross-encoder` weights load
into memory on container start. Acceptable for a demo, documented as a trade-off rather than
hidden.

## Alternatives

- **GKE Autopilot** — rejected. Cluster management fee and node cost accrue even at zero traffic;
  no Always-Free equivalent.
